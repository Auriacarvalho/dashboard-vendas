📊 DESAFIO DE Dashboard de Vendas – Excel
📌 Descrição do Projeto

Este projeto tem como objetivo criar um dashboard de vendas no Excel, transformando dados brutos em informações visuais que auxiliem na análise de desempenho e tomada de decisões.

📁 Dados Utilizados

Os dados utilizados estão no arquivo base.xlsx e contêm informações de vendas como (exemplo):

Data

Produto

Categoria

Quantidade

Valor de venda

📈 Dashboard

O dashboard apresenta:

Indicadores de desempenho (KPIs)

Gráficos de vendas por período e produto

Filtros interativos para análise dinâmica

▶️ Como Reproduzir

Baixe o repositório

Abra o arquivo dashboard.xlsx

Atualize os dados, se necessário, na planilha base

Atualize as tabelas dinâmicas
